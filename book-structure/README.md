# Chapter map

One entry per chapter of Sūtrasthāna 1–5 with its topic groups (taken from
`tools/authored/sections.py`). Each unit is one printed verse-pair of the
1888 Marathi-printed edition, so the pairing can sit one line off from the
real verses (see the README).

Kalpasthāna (quiz chapters 501–508, labels "कल्प अध्याय 1–8"): topic groups from
`tools/authored/sections_kalpa.py`. Units are the edition's two-line pairs of
the reviewed Part 5 layer lines (`data/part5_layer_unit_map.json`).
